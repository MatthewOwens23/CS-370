CS 370 Module Eight Journal: Pirate Intelligent Agent

Project Overview: What Work Did I Do?

For this project, I worked on creating an intelligent agent that could solve a maze and find treasure using reinforcement learning. The goal was to train the pirate agent to find the treasure while learning which actions were most effective. I was provided with starter code that included the maze environment, game logic, neural network setup, and supporting functions. My main responsibility was completing the Q-training algorithm in the Jupyter Notebook.

I wrote the code that allowed the agent to explore the maze, choose actions based on what it had learned, and improve its decisions through training. I also implemented experience replay, trained the model using batches of previous experiences, updated the target network, and tracked the agent's progress. I used the completion check to verify that the agent could successfully solve the maze. This project helped me understand how reinforcement learning and neural networks can work together to solve problems through trial and error.

What Do Computer Scientists Do and Why Does It Matter?

Computer scientists solve problems by designing, developing, and improving software and other computing systems. Their work matters because technology is used in almost every industry, including healthcare, education, business, and cybersecurity. Computer scientists help create solutions that make tasks more efficient, improve decision-making, and address problems that would be difficult to solve manually. This project showed me how computer science can be used to create an intelligent system that learns from experience instead of relying entirely on a set of predefined instructions.

How Do I Approach a Problem as a Computer Scientist?

I approach problems by breaking them into smaller parts, understanding the requirements, and testing possible solutions. In this project, I had to understand how the maze environment worked before implementing the training algorithm. I then used exploration and exploitation to help the agent learn which actions led to better results. Testing and reviewing the agent's performance helped me determine whether my implementation was working correctly. I also learned the importance of working with existing code rather than changing parts of a project that were already provided and functioning properly. These skills can help me approach future programming problems in a more organized and effective way.

What Are My Ethical Responsibilities to the End User and the Organization?

As a computer scientist, I have a responsibility to develop systems that are reliable, secure, fair, and transparent. When working with artificial intelligence, it is important to understand that a system can make incorrect decisions or produce unexpected results. Developers should test their systems carefully, identify potential risks, and make sure users understand the limitations of the technology. They also need to protect user data, respect privacy, and follow applicable laws and organizational policies. I believe it is important to consider how a system could affect people before putting it into use. This project helped me see that developing an AI system involves more than making the code work; it also requires making sure the system is tested and used responsibly.
